## 2. 报告提示词动态切换机制

整个项目最不直观的一段逻辑。LLM 自己决定调用 `fill_context_for_report` 这个空工具，触发中间件改 runtime context，**下一轮**模型生成时 `dynamic_prompt` 才感知到，于是切到报告提示词。三处必须同步改：工具定义、`monitor_tool` 拦截分支、`report_prompt_switch` 读取键名。

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户
    participant A as ReactAgent.execute_stream
    participant DP as @dynamic_prompt<br/>report_prompt_switch
    participant L as ChatTongyi(qwen3-max)
    participant MT as @wrap_tool_call<br/>monitor_tool
    participant T as fill_context_for_report
    participant RT as runtime.context

    U->>A: "给我生成我的使用报告"
    A->>RT: 初始化 context={"report": False}

    Note over A,L: 第 1 轮：还在用主提示词
    A->>DP: 准备调模型
    DP->>RT: get("report") → False
    DP-->>A: 返回 main_prompt.txt
    A->>L: messages + main_prompt
    L-->>A: tool_call: fill_context_for_report

    A->>MT: 执行工具
    MT->>T: handler(request)
    T-->>MT: "fill_context_for_report已调用"
    MT->>RT: context["report"] = True   ← 关键
    MT-->>A: ToolMessage

    Note over A,L: 第 2 轮：dynamic_prompt 重新评估
    A->>DP: 准备再次调模型
    DP->>RT: get("report") → True
    DP-->>A: 返回 report_prompt.txt   ← 切换生效
    A->>L: messages + report_prompt
    L-->>A: 报告正文（可能继续调 get_user_id / fetch_external_data 等）

    L-->>U: 流式输出最终报告
```

> 三处同步点：
> - `agent_tools.py:83` 工具名 `fill_context_for_report`
> - `middleware.py:23` 中 `if request.tool_call["name"] == "fill_context_for_report"`
> - `middleware.py:43` 中 `request.runtime.context.get("report", False)`

## 3. RAG 知识库灌库流程

`python -m p6agent智能体_rag项目.rag.vector_store` 触发的离线流程。md5 去重、分片、embedding、Chroma 持久化都在 `VectorStoreService.load_document` 里。

```mermaid
flowchart TD
    Start([__main__: vector_store.py]) --> Init["VectorStoreService.__init__<br/>vector_store.py:16"]
    Init --> ChromaInit["Chroma(<br/>collection_name='agent',<br/>persist_directory='chroma_db')"]
    Init --> Splitter["RecursiveCharacterTextSplitter<br/>chunk_size=200, overlap=20"]

    Start --> Load["load_document()<br/>vector_store.py:33"]
    Load --> List["listdir_with_allowed_type<br/>data/ 下 *.txt / *.pdf<br/>file_handler.py:40"]
    List --> Loop{"对每个文件"}

    Loop --> Md5["get_file_md5_hex<br/>file_handler.py:8"]
    Md5 --> Check["check_md5_hex<br/>读 md5.text 比对"]
    Check -- "已存在" --> Skip["跳过，logger.info"]
    Skip --> Loop

    Check -- "新文件" --> LoadDoc{"按后缀分派"}
    LoadDoc -- ".txt" --> TxtLoader["TextLoader<br/>file_handler.py:58"]
    LoadDoc -- ".pdf" --> PdfLoader["PyPDFLoader<br/>file_handler.py:54"]
    TxtLoader --> Docs["list[Document]"]
    PdfLoader --> Docs

    Docs --> Split["splitter.split_documents"]
    Split --> Embed["DashScopeEmbeddings<br/>text-embedding-v4<br/>model/factory.py:26"]
    Embed --> Add["vector_store.add_documents"]
    Add --> Persist[("./chroma_db/<br/>chroma.sqlite3")]
    Add --> SaveMd5["save_md5_hex<br/>追加到 md5.text"]
    SaveMd5 --> Loop

    Loop -- "全部完成" --> End([结束])
```

> **清库正确做法**：同时删除 `./chroma_db/` 与 `./md5.text`。只删一个会得到「空库 + md5 已记录」 → 后续 `load_document` 把所有文件全跳过 → RAG 永远检索不到东西。
